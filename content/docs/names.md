## The short version

| You'll see | It means |
|---|---|
| **URM ecosystem**, Ultra Round Money, Ultraround Money | The whole ecosystem and community. |
| **$URM** | The ecosystem stablecoin, pegged to $1. |
| **fURM** | Your receipt for $URM deposited in Fountain. Worth more $URM over time. |
| **ULTRAROUND** | The deflationary ETH proxy. |
| **Pods** | ULTRAROUND and HESTIA wrapped on Peapods Finance (pHestia for HESTIA), where they earn yield from volatility. |
| **HESTIA** | The deflationary store of value paired to USDC. |
| **RAGE** | The token backed by HESTIA and ULTRAROUND. |

## Older docs

Before the $URM stablecoin existed, the old GitBook used "URM" or "Ultraround Money Token" for ULTRAROUND. If you read something older that says "URM burns supply", it means ULTRAROUND. On this site, **$URM is always the stablecoin**.

## Check you have the right token

Always compare the contract address before you buy. The full list is on [Contracts](/docs/contracts).
